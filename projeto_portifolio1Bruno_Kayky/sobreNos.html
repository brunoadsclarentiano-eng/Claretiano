Sobre o dicionário

Um projeto que nasceu de uma dificuldade bem conhecida de quem está começando a programar.

Como surgiu a ideia

Toda videoaula de programação usa termos como "endpoint", "framework" ou "merge" como se fossem óbvios. Para quem está começando, cada um desses termos é uma pequena parada obrigatória: ou você para a aula para pesquisar, ou continua sem entender direito.

O Dicionário do Programador nasceu para resolver exatamente essa pausa: um lugar rápido de consultar, com definições em português simples e exemplos de uso, para quem está no início dos estudos em tecnologia. A idéia do seu desenvolvimento era primariamente para mobile, mas resolvemos expandir para um site.

Missão, visão e valores

missão
Tornar os primeiros meses de estudo em programação menos confusos, explicando os termos técnicos que raramente são ensinados diretamente.
visão
Ser a primeira consulta de quem está aprendendo a programar, antes mesmo de uma busca no navegador.
clareza
Cada verbete é revisado para ser entendido por quem nunca ouviu o termo antes, sem depender de outros termos difíceis para explicá-lo.
comunidade
Estudantes podem sugerir termos e exemplos, porque quem está aprendendo sabe melhor do que ninguém onde estão as dúvidas.
