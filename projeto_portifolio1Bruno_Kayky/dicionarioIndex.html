como são as páginas do dicionário

É assim que qualquer termo aparece dentro do aplicativo: definição curta, onde ele é usado e termos parecidos para continuar estudando.

API

termo de integração

Conjunto de regras que permite que dois programas troquem informações entre si, mesmo tendo sido criados por equipes diferentes.

Onde usar: quando um aplicativo de previsão do tempo busca os dados em outro sistema, ele está "consultando uma API".

Veja também: requisição, endpoint, JSON

DOM

termo de front-end

Representação de uma página HTML em forma de árvore, que o navegador usa para desenhar e atualizar o que aparece na tela.

Onde usar: quando o JavaScript muda o texto de um botão sem recarregar a página, ele está "alterando o DOM".

Veja também: HTML, evento, seletor

framework

termo geral

Conjunto de ferramentas e regras prontas que ajuda a construir um sistema mais rápido, em vez de escrever tudo do zero.

Onde usar: React e Django são exemplos de framework, um para telas e outro para o funcionamento por trás do site.

Veja também: biblioteca, boilerplate

git

termo de versionamento

Ferramenta que guarda o histórico de mudanças de um projeto, permitindo voltar a versões anteriores e trabalhar em equipe sem sobrescrever o trabalho de outra pessoa.

Onde usar: antes de mudar um código já funcionando, é comum "criar uma branch no git" para testar em segurança.

Veja também: commit, repositório, GitHub

Como funciona

  1. Encontrou um termo que não conhece?

    Em uma videoaula, em um tutorial ou em uma mensagem de erro.

  2. Pesquisa no aplicativo

    Digita o termo, mesmo sem saber a grafia exata, e o dicionário encontra o verbete.

  3. Entenda o significado

    Lê a definição em português simples e vê em que contexto o termo costuma aparecer.

  4. Segue estudando

    Usa os links de "veja também" para conhecer termos parecidos, sem sair do assunto.
